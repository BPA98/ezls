# ezls
simple 'ls' command written in go 1.26.11

## Usage

```bash
ezls path
```

Additional flags

```bash
*-l* Display files permissions
*-t* Display files type
*-s* Display files size
```

# Building

Just launch: 

```bash
go build .
```
